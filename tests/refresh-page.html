📋 Jei Cover'iai Vis Dar Netinkami:

1. Hard Refresh: Ctrl+F5 arba Ctrl+Shift+R
2. Išvalyti Cache:
• F12 → Application → Storage → Clear site data
• Arba Settings → Privacy → Clear browsing data
3. Patikrinti Console:
• F12 → Console
• Ieškoti klaidų (raudonos žinutės)
4. Incognito Mode:
• Ctrl+Shift+N (Chrome)
• Ctrl+Shift+P (Firefox)
